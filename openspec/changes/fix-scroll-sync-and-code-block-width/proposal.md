## Why

运行一段时间后，发现两处影响体验的问题：
1. 滚动同步是单向的（左→右），右侧滚动时左侧不跟随，在长文档中查看时造成困惑
2. 代码块在预览区渲染过窄，`` ``` `` 包裹的文字只显示一小条，无法正常阅读代码

## What Changes

- **双向同步滚动**：编辑器（左）和预览区（右）任意一边滚动时，另一边按比例跟随
- **代码块宽度修复**：预览区 CSS 中代码块（`<pre><code>`）的宽度限制调整，确保代码完整显示
